    Data & privacy

    Kept on the hub

    Team names and members, notes, and sessions with their goals, repos and comments.

    Passed through the hub

    Terminal output and Claude Code's hook events, live. The last 256 KB of each agent's output is held in memory, so someone joining sees the current screen and a stopped agent's last screen can be looked at (the 20 most recent per team). None of it is written to disk, and it's gone when the hub restarts.

    Never sent to the hub

    Your code and repos. Agents and git run on your Mac, and the GitHub CLI's login stays here too.

    Your GitHub sign-in

    Read-only access to your public profile, used to check who you are. Stored encrypted on this Mac; the hub never saves it.
