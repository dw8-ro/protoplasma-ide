**If you're on 0.4.x or 0.5.0:** after you click Update now, the window closes but Protoplasma keeps running, so the update doesn't go in. Force Quit Protoplasma once (Option-Command-Esc, or right-click it in the Dock with Option held). The update then installs and the app opens on 0.5.1. From 0.5.1 on, Quit, Update now and logging out work normally.

What's new:
- Quit, Update now and logging out close the app properly (they used to leave it running with no window).
- Codex: its "Trust this folder?" question now shows as **Needs you**, like Claude Code's.
- On a Mac with only Codex (or only OpenCode), Add agent uses the agent you have instead of trying Claude Code.
- Inviting someone to a team hosted on your Mac no longer sometimes fails with "Couldn't reach the team's hub".
- A GitHub CLI login that can't see Protoplasma's repo is told so when checking for updates.
- Fixes from a full customer run-through of 0.5.0, more tests, and new screenshots.
