**Security fixes, after Protoplasma's code went public.** Update soon, especially if your team is hosted on someone's Mac or you share your agents' files with teammates.

**If you're on 0.4.x or 0.5.0:** after you click Update now, the window closes but Protoplasma keeps running, so the update doesn't go in. Force Quit Protoplasma once (Option-Command-Esc, or right-click it in the Dock with Option held). The update then installs and the app opens on 0.5.3.

What's fixed:
- Teams hosted on a Mac: every time Protoplasma connects, it checks that the hub at the team's address is still the team owner's, so another device on the network can't stand in for it.
- Sharing your agents' files (Settings → Agents, off by default): a teammate can open only files your agent changed. Links, and files that were already there when the agent started (like a `.env`), are never sent.
- Claude Code no longer sends the hub the output of every tool it runs. The hub only gets what it needs to warn about edits that overlap.
- Add an agent uses a session's repo only as the person who started it (or the team owner) set it, so a teammate can't point your one-click agent at a repo of their choosing.
- Show in Finder shows a repo's folder and never opens it.
- An update is installed only when the signed app inside it is the version the release says.
- The hub limits sign-ins, agents, sessions and file requests per person, so nobody can wear it down for everyone else.
- Electron 44.8.0, with Chromium's latest security fixes.

Teammates still on 0.5.2 can keep working with you; ask them to update when they can.
