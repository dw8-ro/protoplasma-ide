**Faster, safer updates.** This release changes how Protoplasma updates itself. You'll notice it from the next update on, because the one that brings you 0.5.4 still runs your current version's updater.

**If you're on 0.4.x or 0.5.0:** after you click Update now, the window closes but Protoplasma keeps running, so the update doesn't go in. Force Quit Protoplasma once (Option-Command-Esc, or right-click it in the Dock with Option held). The update then installs and the app opens on 0.5.4.

What's new:
- Update now shows how far the download has got, as a percentage.
- Protoplasma reopens on the new version as soon as the old one has quit, without waiting for the old copy to be cleaned up.
- If an update can't replace the app, the old version is always put back and opens again, with a message saying what happened.
