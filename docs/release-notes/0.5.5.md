**Security fixes.** This release closes several gaps found after the last review. Nothing here changes how you use Protoplasma.

What's fixed:
- A teammate can no longer answer an agent's "Do you trust this folder?" prompt, even in an agent that lets teammates type. Only the person at that Mac can.
- Agents on a shared team can't delete a shared tag, and Claude Code asks before running git through an inline alias that could hide a push.
- A hub on another Mac can't freeze or crash your window by sending a malformed update or a huge terminal size.
- Commit & Push stops after 15 minutes if a repo's own commit hook hangs, instead of waiting forever.
- The hub refuses connections that send their request too slowly, and limits how fast a window can switch sessions or open stopped agents.
