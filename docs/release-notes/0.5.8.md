**Security fix.** Update soon if you're on a team with other people.

**If you're on 0.4.x or 0.5.0:** after you click Update now, the window closes but Protoplasma keeps running, so the update doesn't go in. Force Quit Protoplasma once (Option-Command-Esc, or right-click it in the Dock with Option held). The update then installs and the app opens on 0.5.8.

What's fixed:
- A team's hub could tell Claude Code to approve or change what your agent was about to do. Its answers now pass through Protoplasma on your Mac, which only lets through the team's context and a request to ask you first. A hub can't approve, block or change anything your agent does.
- A hub sending an unexpected agent status can no longer stop the window from redrawing.
- Protoplasma's own builds on GitHub no longer leave a GitHub token where the packages they install could read it.
