**A tidier look.** Things line up, and there's less colour where it doesn't say anything.

**If you're on 0.4.x or 0.5.0:** after you click Update now, the window closes but Protoplasma keeps running, so the update doesn't go in. Force Quit Protoplasma once (Option-Command-Esc, or right-click it in the Dock with Option held). The update then installs and the app opens on 0.5.9.

What's new:
- Session tiles are all the same height, with who's in a session and when along the bottom, so a busy session no longer pushes the others out of line.
- A session's status, how many agents are running and which ones share one line.
- Switches in Settings are black and white like the buttons, and a long description stays beside its switch.
- In a session's panel, agent cards hang on a grey line; each person's colour stays in their picture.
- Every dropdown uses the same thin arrow.
