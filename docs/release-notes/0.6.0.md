**Codex joins the team, and work can move between people.**

**If you're on 0.4.x or 0.5.0:** after you click Update now, the window closes but Protoplasma keeps running, so the update doesn't go in. Force Quit Protoplasma once (Option-Command-Esc, or right-click it in the Dock with Option held). The update then installs and the app opens on 0.6.0.

What's new:
- Codex agents now get the team's context with every prompt, as Claude Code does: the session's goal and plan, the team's notes, and what teammates' agents are changing. The first time, Codex asks you to review Protoplasma's hooks: choose Trust all and continue.
- Before a Codex agent changes a file a teammate's agent has changed, or pushes to main, it's stopped once and told to check with you. If you say yes, it goes ahead.
- Continue on a teammate's agent, running or stopped, starts your own agent where theirs left off, with their last prompt, the files they changed, the end of their screen, and which of their changes aren't pushed yet.
- Hand off on your own agent offers the work to a teammate. It shows in their alerts until they start an agent in that session.
- Ask my agent on a comment sends it, with the lines it's about, to your agent in the session, or starts one with it.
- A note pinned to a file says File changed since once your copy of the file is different from when the note was written.
