**Small fixes, security updates, and lighter teammates' terminals.**

**If you're on 0.4.x or 0.5.0:** after you click Update now, the window closes but Protoplasma keeps running, so the update doesn't go in. Force Quit Protoplasma once (Option-Command-Esc, or right-click it in the Dock with Option held). The update then installs and the app opens on 0.6.1.

What's new:
- Electron 44.10.2, with the latest security fixes from Chromium.
- Switching between the light and dark themes now recolours terminal text already on screen, not only what comes after.
- Agents' colours are right even when a colour code arrives split across two pieces of output.
- A teammate who opens an agent late no longer sees stray characters at the top of its screen.
- Teammates' terminals keep the last 2,000 lines, about what someone joining late gets. With several busy teammates on screen, the app uses 30–40 MB less memory. Your own agents still keep 5,000 lines.
