**An agent's status you can trust, and less sent to the hub.**

**If you use Codex:** it shows "Hooks need review" once more, for two new hooks (its questions, and interrupts). Pick
**Trust all and continue**. The four it already trusted are unchanged.

What's new:
- **Interrupted means Idle.** Press Esc (or Ctrl-C) while an agent works, and its card goes to Idle a moment later.
  Before, Claude Code stayed on Working until its next prompt finished, and "Your agent finished" never came.
- **A question is Needs you.** When Claude Code asks you to choose, or has a plan for you to approve, its card says
  Needs you and you get the alert. The same for a question from Codex.
- **Approved means Working.** After you answer a permission, the card goes back to Working at once. Before, it said
  Needs you until that command ended, which for a long test run was minutes.
- **Needs you survives sleep.** A Codex agent waiting on you still says so after your Mac wakes up or the connection
  drops. Before, it could turn into Idle.
- **Your files stay on your Mac.** The app now takes everything the hub doesn't use out of each hook before it goes:
  the hub gets which tool is about to run, the file's name or the command, and the first 300 characters of a prompt.
  The text your agent writes into a file, and the rest of your prompts, no longer pass through. This also means a very
  large write is still checked against your teammates' changes.
- Electron 44.11.3, with the latest security fixes from Chromium.

How the status works now: hooks still say when an agent starts, asks permission and finishes. Where no hook says
anything (an interrupt, an answered permission), Protoplasma looks at what the terminal did after your key: still
printing means it went back to work, and a still screen after Esc means it stopped.
