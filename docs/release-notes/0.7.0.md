**A simpler, quieter look, no team needed to start, an agent's status you can trust, any agent CLI, and a warning before branches conflict.**

**If you use Codex:** it shows "Hooks need review" once more, for two new hooks (its questions, and interrupts). Pick
**Trust all and continue**. The four it already trusted are unchanged.

Starting work:
- **No team needed to start.** Sign in and you're in **Just me**, your own space on this Mac that nobody else sees.
  Make a team, or join one you're invited to, whenever you want to work with people: "You were added to …" shows in
  the sidebar. Anyone who already has a team opens it as before.
- **Move to a team…** in a session's menu carries it into a team: same goal, and your agents there work in the same
  folder and branch, so the work carries on.
- **New session asks one thing: what should the agent do?** What you type is the session's goal and the agent's first
  message, so you don't type it twice. The session is named after it (you can still name it yourself), and the rest is
  under More options.
- **Any agent CLI.** Put a command in Settings → Agents → **Other command** (`gemini`, for example) and it runs like
  the others: a shared terminal, overlap warnings from git, and the push guard. It has no hooks, so its status is a
  guess from its output.
- **OpenCode gets hooks**, through a plugin Protoplasma loads for that run: the team's context, a stop before an edit
  that would overlap a teammate's, the push guard, and a status that follows what it's doing. They're written from
  OpenCode 1.19.5's plugin interface and haven't yet run against a live model, so tell us what you see.

The look:
- **Quieter and roomier.** Terminals sit edge to edge, the session panel is a column of the window, buttons are softer,
  and alerts keep their colour to a small dot. Still black and white.
- **The bar under a terminal is shorter.** Whose agent and which CLI sit above it ("Me · Claude Code"); the bar is its
  status, changes and branch, and what you can do.
- **Open beside** (was New pane) puts another agent of the session, or another session, next to this one.
- **Red for what you can't take back:** Sign out, Leave or Delete team, Remove someone and Delete session. Leave team
  has its own row, away from Switch team.
- An overlap alert says **Compare versions** and opens the file with the Conflicts list beside it.

Working together:
- **Conflicts with other sessions, before either is merged.** When your session's commits would conflict with another
  session's pushed branch, the card says "Conflicts with <that session>", the files are listed under Environment, and
  your agent is told, so you can agree who changes them first.
- **Plan steps can claim files.** Name a file in a plan step ("Lock the seat row in session_store.ts"), and a
  teammate's agent about to edit it is told whose step it is.
- **Conflicts with main, before the pull request.** When your session's commits would conflict with main if merged
  today, its card says "N conflicts with main", the files are listed under Environment, and your agent is told.
- **Interrupted means Idle.** Press Esc (or Ctrl-C) while an agent works, and its card goes to Idle a moment later.
  Before, Claude Code stayed on Working until its next prompt finished, and "Your agent finished" never came.
- **A question is Needs you.** When Claude Code asks you to choose, or has a plan for you to approve, its card says
  Needs you and you get the alert. The same for a question from Codex.
- **Approved means Working.** After you answer a permission, the card goes back to Working at once. Before, it said
  Needs you until that command ended, which for a long test run was minutes.
- **Needs you survives sleep.** A Codex agent waiting on you still says so after your Mac wakes up.

Privacy and weight:
- **Your files stay on your Mac.** The app now takes everything the hub doesn't use out of each hook before it goes:
  the hub gets which tool is about to run, the file's name or the command, and the first 300 characters of a prompt.
  The text your agent writes with its edit tools, and the rest of your prompts, no longer pass through (a shell
  command still goes whole, as it always has, for the push and overlap checks).
- **Terminal output goes only where it's watched.** An agent's output is sent to teammates who have its session on
  screen, not to everyone on the team, and the app keeps a terminal for a teammate's agent only while you're looking.
- Terminal text that was drawn at the wrong size after the display's scale changed now corrects itself.
- **No early "Your agent finished"** from an agent whose status is guessed (Codex before its hooks are trusted, an
  Other command): it waits until the agent has stayed quiet a while.

Smaller things: **Share** in a session is now **Invite**; an agent that hasn't reported yet reads Idle, not Running;
creating an online team where only the hub's owners can now says so and offers This Mac.

Fixed after an independent review before release:
- **Codex and OpenCode are stopped once per step, not once per reason.** One risky push refused and retried no longer
  lets a different push with the same reason through within 10 minutes. (Also in 0.6.x for Codex.)
- **A session squash-merged into main** no longer shows as a conflict forever, or tells your agent about one.
- **Delete session** no longer offers to remove a folder that a moved copy of the session, or a running agent, still
  uses. **Move to a team** won't join a session of the same name there; it asks you to rename first.
- **Inviting someone into Just me** says first that they'll see everything in it.
- **New session** sends the agent everything you typed; only the session's goal is cut to 300 characters.
- **The push guard** also catches `remote.<name>.mirror`, `--config-env` and `GIT_CONFIG_KEY_n` redirects. Plan
  steps no longer claim a file whose name sits inside another (`a.ts` in `data.ts`), and none after the third is lost.
- **Checks for conflicts leave nothing behind** in your repo (they used to leave loose git objects).
- The hub drops a window that stops reading instead of queueing replays for it; the window survives odder data from a
  hub; checking for invites on window focus happens at most once a minute.
- **Setup is stricter:** `npm run setup` runs only the vetted copy of each allowed package. Releases are now built in a
  job without the signing certificate, and signed in a separate one that installs nothing.
- Electron 44.11.6 (Chromium security fixes; the terminal font bug that kept 0.6.x on 44.10.2 is fixed there) and
  Monaco 0.58.0.
