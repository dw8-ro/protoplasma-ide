**0.5.5 (26 Oct, `5c9632c`): a security follow-up (`8df2f17`).**
- Hub:
  - over-long URL path segments are refused;
  - `findSession` slugs the name once per lookup;
  - `look`/`replay` have a budget per socket;
  - the HTTP server has header and request timeouts.
- Push guard:
  - Claude Code is asked about git run through an inline alias (`-c alias.x=push`);
  - the Codex/OpenCode pre-push hook refuses deleting a shared tag.
- Lanes ignore a teammate's typing while the folder-trust prompt is up, so only the person at that Mac can answer it.
- Renderer: the terminal size a hub sends is clamped, and a malformed `state` frame can't wedge the watch socket.
- Commit & Push: `git commit` times out after 15 minutes, so a hung pre-commit hook can't wedge it.
- Docs: `allowScripts` isn't enforced (no lavamoat or `.npmrc`), and README and AGENTS now say so.
- CI had two flaky lane lifecycle tests (`fa6c020`). One hub test then failed every run, because it answered the
  trust prompt from a teammate (`8942804`). Both are fixed. CI and the Release, Package and CI runs on `5c9632c` are
  green.
- The hosted hub redeploys from the `src/hub.js` change on `main`. Its health check answered on 27 Oct.
