## The look to build (all in app/index.html's CSS, nothing built yet)
1. **Flat panes in a session.** Terminals lose their card (no border, no radius, no 14px inset) and sit edge to
   edge, split by a hairline: `.lanes { gap: 0; padding: 0 }`, `.lane { border: 0; border-radius: 0;
   box-shadow: -1px 0 0 var(--line) }` (a shadow, because `.lane.mine` is reordered and hidden lanes stay in the
   DOM, so `.lane + .lane` picks the wrong one), `.pane-body { padding: 0 }` with `.pane-body .lane { box-shadow:
   none }`. Which terminal has focus: `.lane:focus-within .lane-label { color: var(--text) }`.
2. **The session panel is a flush column,** not a floating card: `.panel { margin: 0; border: 0; border-left: 1px
   solid var(--line); border-radius: 0; background: none; --stack-bg: var(--main) }`; in the code view,
   `.room.coding .panel { margin-top: 0 }` and `.room.coding .lanes { padding-top: 0 }`.
3. **The bar under a terminal is a status line:** no `border-top`, the agent's name (`.tag`) without its box, and
   the buttons pushed right: `.lane-bar > :is(.access, .btn) { margin-left: auto }` and
   `.lane-bar > :is(.access, .btn) ~ .btn { margin-left: 0 }`. e2e checks Stop is fully visible ("Stop button is
   fully visible on your pane").
4. **Soft buttons:** `.btn` with no border and a see-through fill (new tokens `--fill` and `--fill-hover`: white at
   6% and 10% in dark, black at 5% and 8% in light); primary stays white (black in light). Keep heights (32, small
   26): the dialogs' layout and the customer simulation's clicks depend on them.
5. **Quieter alerts** in the sidebar: a neutral `--fill` block with the status colour only in a 6px dot before the
   title (`.alert b::before`), not a tinted, outlined box.
6. **A flat title bar:** the team switch has no box until hover.
7. **Smaller things:** hover fills and a 120 ms `background-color` transition on sidebar links, menu rows, panel
   rows and tree rows; the Sessions search and sort as soft fields; `font-variant-numeric: tabular-nums` on `.diff`
   and `.ago`; page title 20px.

Left as it is, on purpose: the colours of `--canvas`, `--main`, `--lane` (the terminal background `#141416` /
`#ffffff` must equal `--lane`, and readme-art's crop uses it), session cards keep a hairline (in light they are white
on white), the agent cards' grey guide line and the flat avatars (David chose both on 29 Oct).

## Traps found
- **Don't make `--line` or `--line-strong` see-through** without changing code.js `editorTheme`: it appends `99` to
  `--line-strong` for Monaco's scrollbar (`${cssVar('--line-strong')}99`), which only works on a six-digit hex.
  renderer.js `startCellArt` reads `--line-strong` too (a canvas colour; any CSS colour works there).
- The theme tiles in Settings hard-code the canvas and line colours (`.tile`, `.tile i`).
- e2e reads the dialog's height before and after an error, and the positions of `.stage` and `#code`.
- A new worktree needs `npm ci` (the app's HTML loads xterm from its own `node_modules`).
